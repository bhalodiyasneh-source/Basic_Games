# Rock Paper Scissors Game

This is a web-based **Rock Paper Scissors** game built using **HTML, CSS, PHP, and Python**.

### Features:
- Beautiful frosted glassmorphism UI.
- Backend powered by PHP (`Process.php`) and Python (`Game_Logic.py`).
